# Complete Deep Explanation of the K-Means Clustering Code

This program performs **K-Means Clustering** on the famous Iris dataset using Python.

It:

1. Loads the dataset
2. Preprocesses the data using scaling
3. Applies the K-Means clustering algorithm
4. Gets cluster labels
5. Visualizes the clusters using a scatter plot

---

# Full Code

```python
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

iris = load_iris()
X = iris.data

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

kmeans = KMeans(n_clusters=3, random_state=42)
kmeans.fit(X_scaled)

labels = kmeans.labels_

print("Cluster Labels:")
print(labels)

plt.figure(figsize=(8,6))
plt.scatter(
    X_scaled[:, 0],
    X_scaled[:, 1],
    c=labels,
    cmap='viridis'
)

plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    s=200,
    c='red',
    marker='X'
)

plt.xlabel("Scaled Sepal Length")
plt.ylabel("Scaled Sepal Width")
plt.title("K-Means Clustering with Preprocessed Data")
plt.show()
```


# Purpose

Imports scaling tool.

Used to standardize data.

---

# Why scaling is needed?

K-Means uses distance calculation.

If features have different ranges:

* larger values dominate

Example:

| Feature | Range    |
| ------- | -------- |
| Age     | 0–100    |
| Salary  | 0–100000 |

Salary dominates distance.

Scaling fixes this.

---

# What StandardScaler Does

Uses formula:

genui{"math_block_widget_always_prefetch_v2":{"content":"z = \frac{x-\mu}{\sigma}"}}

Where:

* (x) = original value
* (\mu) = mean
* (\sigma) = standard deviation

---

# Result

After scaling:

* mean becomes 0
* standard deviation becomes 1

# MOST IMPORTANT PREPROCESSING STEP

This does TWO operations:

1. `fit`
2. `transform`

---

# Step 1 — fit()

Computes:

* mean
* standard deviation

for every column.

---

# Example

Suppose feature column:

```python
[1,2,3]
```

Mean:

\mu = \frac{1+2+3}{3}

Standard deviation measures spread.

---

# Step 2 — transform()

Applies scaling formula:

genui{"math_block_widget_always_prefetch_v2":{"content":"z = \frac{x-\mu}{\sigma}"}}

to every value.

---

# Internal Workflow

For each column:

1. Calculate mean
2. Calculate std
3. Loop through each value
4. Replace with scaled value

# Result

All features now:

* centered near 0
* equally weighted

# PART 5 — TRAINING MODEL

---

# Line 14

```python
kmeans.fit(X_scaled)
```

# MOST IMPORTANT LINE

Trains clustering model.

---

# Internal Working of K-Means

---

# STEP 1 — Random Centroid Initialization

Algorithm randomly picks 3 points.

These become temporary centers.

---

# STEP 2 — Distance Calculation

For every data point:
calculate distance from each centroid.

Usually Euclidean distance.

Formula:

genui{"math_block_widget_always_prefetch_v2":{"content":"d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}"}}

---

# STEP 3 — Assign Cluster

Point assigned to nearest centroid.

---

# STEP 4 — Update Centroids

Centroid becomes average of cluster points.

Formula:

C = \frac{x_1+x_2+\cdots+x_n}{n}

---

# STEP 5 — Repeat

Repeat:

* distance calculation
* reassignment
* centroid update

until centroids stop moving.

---

# Convergence

When clusters stabilize:
algorithm stops.

# TIME COMPLEXITY

K-Means complexity approximately:

O(n \times k \times i \times d)

Where:

* (n) = data points
* (k) = clusters
* (i) = iterations
* (d) = dimensions

---

# WHY PREPROCESSING IS IMPORTANT

Without scaling:

* features with large values dominate
* clustering becomes poor

With scaling:

* all features contribute equally

---

Dataset has 4 dimensions.

Humans can easily visualize:

* only 2D or 3D

So graph uses:

* feature 1 on X-axis
* feature 2 on Y-axis

Even though K-Means internally used ALL 4 features.
