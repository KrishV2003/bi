# 1. WHAT IS CLUSTERING?

## Simple Definition

Clustering is an **unsupervised machine learning technique** used to group similar data points together.

The goal is:

* Similar data points → same cluster
* Different data points → different clusters

---

# 2. WHAT IS UNSUPERVISED LEARNING?

In unsupervised learning:

* Data has **NO labels**
* Machine tries to discover hidden patterns itself

Example:

| Student | Marks |
| ------- | ----- |
| A       | 90    |
| B       | 92    |
| C       | 30    |
| D       | 35    |

Machine automatically forms:

* Cluster 1 → High scorers
* Cluster 2 → Low scorers

No teacher tells the machine.

# 10. BASIC IDEA OF K-MEANS

Suppose:

```text
K = 3
```

Means:
Create 3 clusters.

Algorithm:

1. Pick 3 centroids randomly
2. Assign points to nearest centroid
3. Update centroid
4. Repeat until stable

---

# 11. STEP-BY-STEP K-MEANS

Suppose data:

| Point | X | Y |
| ----- | - | - |
| A     | 1 | 1 |
| B     | 2 | 1 |
| C     | 4 | 3 |
| D     | 5 | 4 |

Take:

```text
K = 2
```

---

# STEP 1 — RANDOM CENTROIDS

Suppose:

```text
C1 = (1,1)
C2 = (5,4)
```

---

# STEP 2 — CALCULATE DISTANCE

Distance formula:

genui{"math_block_widget_always_prefetch_v2":{"content":"d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}"}}

This is Euclidean Distance.

---

## Example

Distance between:

```text
A(1,1)
C1(1,1)
```

d = \sqrt{(1-1)^2 + (1-1)^2} = 0

Assign A to Cluster 1.

---

# STEP 3 — ASSIGN ALL POINTS

Each point goes to nearest centroid.

---

# STEP 4 — UPDATE CENTROID

New centroid formula:

Centroid = \left(\frac{\sum x}{n}, \frac{\sum y}{n}\right)

Example:

If cluster has:

```text
(1,1), (2,1)
```

Then:

Centroid = \left(\frac{1+2}{2}, \frac{1+1}{2}\right) = (1.5,1)

---

# STEP 5 — REPEAT

Repeat until centroids stop changing.

This is called:

# CONVERGENCE

---

# 12. LOSS FUNCTION OF K-MEANS

VERY IMPORTANT.

K-Means tries to minimize:

# Within Cluster Sum of Squares (WCSS)

Also called:

* Inertia
* SSE (Sum of Squared Errors)

Formula:

J = \sum_{i=1}^{k} \sum_{x \in C_i} ||x - \mu_i||^2

Where:

| Symbol | Meaning            |     |   |   |                  |
| ------ | ------------------ | --- | - | - | ---------------- |
| J      | Loss function      |     |   |   |                  |
| k      | Number of clusters |     |   |   |                  |
| x      | Data point         |     |   |   |                  |
| μ      | Centroid           |     |   |   |                  |
|        |                    | x−μ |   | ² | Squared distance |

---

# SIMPLE MEANING OF LOSS FUNCTION

Algorithm tries to:

## Make points as close as possible to centroid.

Smaller loss = better clustering.

---

# 13. WHY SQUARED DISTANCE?

Because:

* penalizes far points more
* easier mathematically
* smooth optimization

---

# 14. ELBOW METHOD

Question:

# How to choose K?

Answer:
Use Elbow Method.

---

## Process

1. Run K-Means for different K values
2. Compute WCSS
3. Plot graph

Graph shape:

```text
\
 \
  \
   \__
```

The bend point = optimal K.

---

# 15. SILHOUETTE SCORE

Measures clustering quality.

Range:

```text
-1 to +1
```

| Value | Meaning          |
| ----- | ---------------- |
| +1    | Excellent        |
| 0     | Overlapping      |
| -1    | Wrong clustering |

Formula:

s = \frac{b-a}{\max(a,b)}

Where:

| Symbol | Meaning                        |
| ------ | ------------------------------ |
| a      | average intra-cluster distance |
| b      | nearest-cluster distance       |

# 16. DISTANCE METRICS

Clustering heavily depends on distance.

---

# A. EUCLIDEAN DISTANCE

Most common.

d = \sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}

Straight-line distance.

---

# B. MANHATTAN DISTANCE

City-block distance.

d = \sum_{i=1}^{n}|x_i-y_i|

---

# C. MINKOWSKI DISTANCE

Generalized form.

d = \left(\sum |x_i-y_i|^p\right)^{1/p}

# 21. FUZZY C-MEANS CLUSTERING

In K-Means:

Point belongs to ONE cluster.

In Fuzzy Clustering:

Point can belong to multiple clusters.

Example:

```text
70% Cluster A
30% Cluster B
```

Useful in medical systems.

---

# 22. GAUSSIAN MIXTURE MODEL (GMM)

Probabilistic clustering.

Uses Gaussian distributions.

Instead of hard assignment:

```text
Point definitely belongs to Cluster 1
```

It says:

```text
Point has 80% probability of Cluster 1
```

---

# 23. EXPECTATION MAXIMIZATION (EM)

GMM uses EM algorithm.

Two steps:

| Step         | Work                  |
| ------------ | --------------------- |
| Expectation  | Compute probabilities |
| Maximization | Update distributions  |

Each iteration:

# 38. CONCLUSION

Clustering is one of the most important unsupervised learning techniques in Machine Learning. It helps in discovering hidden structures in unlabeled data. Different clustering algorithms use different mathematical ideas such as distance minimization, density estimation, probability distributions, and hierarchical merging to group similar data points together.

The most important clustering algorithm is K-Means, which minimizes the WCSS loss function using centroid optimization. Other advanced algorithms like DBSCAN, Hierarchical Clustering, and Gaussian Mixture Models solve problems where K-Means fails.

Clustering is widely used in AI, business analytics, healthcare, cybersecurity, recommendation systems, and image processing.
