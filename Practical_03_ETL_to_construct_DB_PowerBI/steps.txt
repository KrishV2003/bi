THEORY
===========================================================

ETL stands for:

E -> Extraction
T -> Transformation
L -> Loading

ETL is one of the most important processes used in
Data Warehousing, Business Intelligence and Data Analytics.

It helps in collecting data from different sources,
cleaning and transforming the data, and loading it into
a target system for reporting and analysis.

-----------------------------------------------------------
1. EXTRACTION
-----------------------------------------------------------

Extraction means collecting or importing data from
different sources.

The data may come from:
- Excel files
- SQL Server
- Oracle Database
- CSV files
- APIs
- OData Feed
- Cloud Databases

Purpose of Extraction:
- Gather raw data
- Combine data from multiple sources
- Prepare data for analysis

Types of Extraction:
1. Full Extraction
   - Entire data is extracted.
   - Used for first-time loading.

2. Incremental / Partial Extraction
   - Only changed or updated data is extracted.
   - Saves time and resources.

-----------------------------------------------------------
2. TRANSFORMATION
-----------------------------------------------------------

Transformation means modifying, cleaning and converting
the extracted data into useful format.

Transformation operations include:
- Removing null values
- Changing data types
- Renaming columns
- Filtering rows
- Merging tables
- Splitting columns
- Sorting data
- Removing duplicates
- Creating calculated columns

Purpose of Transformation:
- Improve data quality
- Make data consistent
- Prepare data for analysis and visualization

-----------------------------------------------------------
3. LOADING
-----------------------------------------------------------

Loading means storing transformed data into the target
system like:
- Data Warehouse
- SQL Server
- Power BI Model

Purpose:
- Final data becomes available for reporting,
  dashboards and analytics.

===========================================================
PROCEDURE / STEPS
===========================================================

-----------------------------------------------------------
STEP 1: OPEN POWER BI DESKTOP
-----------------------------------------------------------

1. Open Microsoft Power BI Desktop.
2. Wait until the Home screen appears.

-----------------------------------------------------------
STEP 2: IMPORT DATA USING ODATA FEED
-----------------------------------------------------------

1. Click on Home Tab.
2. Select "Get Data".
3. Choose "OData Feed".
4. Paste the following URL:

   https://services.odata.org/Northwind/Northwind.svc

5. Click OK.
6. Navigator window will open.
7. Select:
   - Orders table
   - Products table
8. Click "Transform Data".

-----------------------------------------------------------
STEP 3: DATA EXTRACTION
-----------------------------------------------------------

Power BI extracts data from the OData service.

Extracted tables:
- Orders
- Products

The extracted data appears inside Power Query Editor.

-----------------------------------------------------------
STEP 4: DATA TRANSFORMATION
-----------------------------------------------------------

=============================
A. TRANSFORM PRODUCTS TABLE
=============================

1. Open Products table.

2. Remove unnecessary columns.

Keep only:
- ProductID
- ProductName
- QuantityPerUnit
- UnitsInStock

3. Rename columns if required.

4. Change data type of UnitsInStock:
   - Select UnitsInStock column
   - Change datatype to Whole Number

Purpose:
- To ensure numerical calculations work properly.

=============================
B. TRANSFORM ORDERS TABLE
=============================

1. Open Orders table.

2. Expand Order_Details column.

3. Select all columns from Order_Details.

Expanded columns include:
- UnitPrice
- Quantity
- Discount

Purpose:
- To access detailed order information.

-----------------------------------------------------------
STEP 5: CREATE CUSTOM COLUMN
-----------------------------------------------------------

1. Go to Add Column tab.
2. Click on Custom Column.

3. Create new column:
   Column Name:
   LineTotal

4. Formula:

   [Order_Details.UnitPrice] *
   [Order_Details.Quantity]

5. Click OK.

Purpose:
- To calculate total amount of each order line.

-----------------------------------------------------------
STEP 6: RENAME AND REORDER COLUMNS
-----------------------------------------------------------

1. Rename columns properly.
2. Move LineTotal column after ShipCountry.

Purpose:
- Better readability and organization.

-----------------------------------------------------------
STEP 7: COMBINE TABLES
-----------------------------------------------------------

1. Merge Orders and Products tables.
2. Use ProductID as matching key.
3. Join related information.

Purpose:
- Combine product details with sales data.

-----------------------------------------------------------
STEP 8: LOAD DATA
-----------------------------------------------------------

1. Click "Close & Apply".
2. Power BI loads transformed data into model.

This completes the Loading phase of ETL.
